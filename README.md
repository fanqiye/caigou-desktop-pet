# 菜狗现代桌宠

这是当前启用的现代 WPF 版本。默认体积约为桌面图标大小，使用透明 PNG 帧动画，不再依赖带调色板的 GIF 或色键抠图。

## 启动

- 在桌面空白处单击鼠标右键，选择“打开动态菜狗桌宠”。
- 也可以双击 `启动动态菜狗.vbs`。
- 不创建桌面快捷方式，不设置开机自启。

## 视觉与反馈

- 12 组动作、71 张 192×208 RGBA 高清帧，使用 WPF 高质量缩放。
- 透明异形窗口、柔和落地阴影、悬停轻微呼吸缩放。
- 摸头、喂食、玩耍、拒绝、边界提醒都有独立反馈卡、色彩语义、状态徽章和粒子效果。
- 反馈配色分为：绿色积极反馈、琥珀色饥饿提醒、玫瑰色生命警告、珊瑚色边界反馈、蓝色体力信息。
- 328px 圆角生活面板集中显示生命、饱食、体力、亲密四条状态和常用控制，不再使用菜狗右键触发。
- 视觉参数集中在 `design-tokens.json`，便于后续统一调整。

## 互动

- 单击头部摸头，单击身体陪玩；鼠标悬停到菜狗上会自动展开完整生活面板，离开菜狗和面板后自动隐藏。
- 右键菜狗不再打开面板；拖动可以移动菜狗，双击菜狗打开 Codex。
- “跟着鼠标”没有 8 秒上限，会一直陪跑；移动时不弹面板，鼠标停稳且菜狗追上后在同一区域保持 5 秒才会显示面板。选择“停止跟随”后，菜狗会自己跑回右下角。
- 面板已经直接展示全部状态，因此删除了重复的“查看状态”按钮。
- 无人互动时采用块状作息，不再按十几秒一次的固定节拍轮播动作：长睡眠、安静清醒、短暂活跃三个阶段会依照时间、精力和随机权重自然轮换。
- 内置 30 种清醒小剧场和 3 种睡眠微动作，包括歪头观察、左右嗅闻、挥爪、抖菜叶、点脚、伸懒腰、玩耍鞠躬、小跳、迷你疯跑、绕圈巡逻、捕捉鼠标方向、打哈欠、睡梦踢爪等。
- 睡眠阶段通常持续 18–45 分钟，夜间可持续 45–120 分钟；睡着后约 6–14 分钟才可能有一次很轻的梦中动作。
- 安静清醒通常持续 10–25 分钟，约 3–7 分钟才换一次姿势；短暂活跃只维持 2–4 分钟，动作间隔约 28–65 秒，之后重新安静或入睡。
- 清醒动作按安静组和活跃组分别洗牌，避免连续重复，又不会把全部动作平均铺满全天。
- 自言自语只会出现在短暂活跃阶段，并且至少间隔 45 分钟；普通耍宝不算“求关注”，没有回应不会扣亲密度。
- 正常求互动由原来的约 15–26 分钟放宽为约 40–75 分钟；睡眠中除非非常饿，不会主动醒来弹提示。
- 用户点击、拖动或打开菜单时会立即打断自主表演，把控制权让给互动。
- 睡眠和安静清醒状态会停在一张自然姿势上，不再永久循环播放帧；只有梦中微动作、主动活动或用户互动时才播放完整动作。

## 生存与关系

- 状态存档包含生命、饱食、体力、亲密，不再把饱食和亲密强制锁在 10。
- 饱食高于 25 时约每小时下降 1；10–25 时约每两小时下降 1；0–10 时约每四小时下降 1，因此越饥饿下降越慢。
- 饱食归零后约每六小时损失 1 点生命。生命归零会真正进入“死亡”状态并离开桌面；重新启动只显示留信和重新领养入口。
- 亲密度会因长期忽视、连续越界摸头、吃饱后强喂和长时间拎着而下降；降到 5 会离开桌面。
- 两种结局都设计为高门槛：正常照顾不会轻易触发；极低饥饿会按 4–16 分钟的间隔反复表达需求。
- 重新领养会创建一段新关系，初始亲密度为 35，不会把已经离开的旧关系伪装成复活。
